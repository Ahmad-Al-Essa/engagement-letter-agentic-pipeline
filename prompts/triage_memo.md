Now write the scope memo for this intake, using only what the tools returned above.

- services: each selected service with its code, a one-sentence reason, and client_quote: the client's words copied exactly from the request, not paraphrased.
- excluded: near neighbours the search returned that you did not select, each with a reason.
- not_offered: needs for which the search found no matching service, each with the client's exact words.
- paused: matching services the search marked PAUSED, each with the client's exact words.
- deadline: the client's deadline in their words, or an empty string.
- open_questions: what a partner would need to ask the client to decide.

Choose the verdict:

- in_scope: every need has a selected service, and none is paused.
- out_of_scope: no need matches any service.
- unclear: some needs match and others do not, a needed service is paused, or the request is too vague to tell which services apply. A partner will decide.
