For each need:

- need: the need in plain words;
- client_quote: the client's words for it, copied exactly from the request;
- code: the one service code from that need's search results that fits it, or an empty string if none fits. A service only fits if it does what the client asks for; a service that merely sounds related does not fit.

Choose the verdict:

- in_scope: every need has a fitting service, and none is paused.
- out_of_scope: no need has a fitting service.
- unclear: some needs have a fitting service and others do not, a fitting service is paused, or the request is too vague to tell which services apply.
